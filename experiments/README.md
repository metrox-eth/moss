# MOSS experiments

Bench work and early ideas for MOSS, the litter-picking rover. These folders are separate from the supported build instructions and describe their own limits.

- **[Orange Pi + MightyCam](orange-pi-mightycam/)** — a $60 computer, an $80 camera, dimOS and YOLO on the NPU. First load measurements, source code and a cockpit image; camera accuracy and robot autonomy remain unvalidated.
